# Diário de Aventureiro

Projeto desenvolvido como parte das atividades da faculdade, inspirado no universo de **Baldur's Gate 3**.

A aplicação permite criar e visualizar personagens de RPG, definir seus atributos e selecionar companheiros para formar uma party.

## Funcionalidades

- Criação de personagens
- Definição de classe, raça e nível
- Distribuição de atributos
- Seleção de até 3 companheiros
- Listagem dos personagens cadastrados
- Visualização dos atributos e companheiros de cada personagem

## Tecnologias

### Backend
- Java
- Spring Boot
- JdbcTemplate
- H2 Database

### Frontend
- HTML
- CSS
- JavaScript

## Estrutura

O projeto é dividido em:

- **Backend:** API REST responsável pelo cadastro e consulta dos personagens e parties.
- **Frontend:** interface para criação e visualização dos personagens.

## Objetivo

O projeto tem como objetivo aplicar na prática conceitos de desenvolvimento de APIs, integração entre frontend e backend, persistência de dados e organização de uma aplicação web.
